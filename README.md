# 🌷 心头好

> *你是我心头，最软的地方。*

**心头好** 是一个治愈系娃娃记录小窝，专为珍惜娃娃的你而做。

它不是库存管理，不是百科图鉴。它是一个**温柔的地方**，帮你好好记得——

你和你的小朋友，一起走过的每一天。

---

## ✨ 打开心头好

**👉 [点击这里直接打开](https://web-theta-gold-26.vercel.app)**

手机、电脑都能用，不用下载，不用注册。

---

## 🌿 它长什么样

治愈水彩风，奶杏配嫩绿，打开就像被轻轻抱住。

- 🖼️ **相框首页** —— 把它最好看的照片放进去，每次打开都对你笑
- 📖 **它的世界** —— 名字、生日、性格、怎么来到你身边，给它写一份专属小档案
- 🌞 **来家第N天** —— 替你数着在一起的日子，每一天都算数
- 📷 **回忆格子墙** —— 照片、文字、心情，一格一格存起来，想它的时候翻一翻
- 👨‍👩‍👧 **家族** —— 娃多的姐妹一个个建好，整整齐齐看着就治愈

---

## 💛 关于隐私

你写下的每一句话、每一张照片，都安安静静存在你自己的浏览器里。

只属于你和它，是你们之间的小秘密。

## 🛠 技术说明

纯静态网页，HTML + CSS + JavaScript，零依赖。

数据存储：localStorage（浏览器本地）

部署：Vercel / GitHub Pages 均可
